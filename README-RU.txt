ELITE FORCE MINI APP — обновлённая сборка для Render

Файлы: index.html, server.js, api.mjs, package.json.
Render: Node >=20, Build Command: npm install, Start Command: npm start.

ОБЯЗАТЕЛЬНЫЕ Environment Variables:
TELEGRAM_BOT_TOKEN — токен из BotFather (никому не отправлять).
TELEGRAM_BOT_USERNAME — username бота без @.
ADMIN_TELEGRAM_ID — числовой Telegram ID администратора.
TELEGRAM_CHANNEL_ID — ID канала (обычно -100...), бот должен быть администратором канала.
TELEGRAM_CHANNEL_URL — публичная ссылка на канал.
DATA_DIR=/var/data

ХРАНЕНИЕ:
В Render добавьте Persistent Disk с Mount Path /var/data и задайте DATA_DIR=/var/data. Без диска локальные JSON-файлы могут исчезнуть после перезапуска/пересборки.

АДМИНКА:
Админ-панель видна только аккаунту, чей Telegram ID точно совпадает с ADMIN_TELEGRAM_ID. Введите только числовой ID, без @ и пробелов. Если открыть админку не тем аккаунтом, появится пояснение, а не пустая страница. Настройки включают вероятности (каждую можно задавать независимо, общая сумма не обязана быть 100%), цены и остатки призов, лимит прокруток, бесплатные попытки, стоимость прокрутки, реферальные награды. Также доступны список пользователей, изменение баланса, начисление монет всем пользователям, начисление по Telegram ID и управление кодами. При обновлении приложения балансы существующих игроков НЕ сбрасываются: накопленные монеты, история, задания и коды остаются в базе. Только новые игроки начинают с 0 монет. Для сохранения данных между перезапусками Render обязательно подключите Persistent Disk с Mount Path /var/data и установите DATA_DIR=/var/data. Не удаляйте и не пересоздавайте диск при деплое.

РУЛЕТКА:
По умолчанию 10 прокруток в сутки, первые 3 бесплатные, остальные стоят 100 монет. Вероятности вводятся как веса в процентах; общая сумма может быть любой. Например, сумма 52% допустима — шансы нормируются относительно суммы введённых значений. Список призов и цены/остатки обмена отображаются из серверных настроек.

ЗАДАНИЕ НА ПОДПИСКУ:
Кнопка «Перейти» открывает TELEGRAM_CHANNEL_URL. После подписки вернитесь в Mini App и нажмите «Проверить». Сервер проверяет подписку через Telegram Bot API. За задание начисляется 50 монет один раз.

РЕФЕРАЛЬНАЯ СИСТЕМА:
Пригласивший получает 70 монет, приглашённый — 35 по умолчанию. Награды выдаются после серверной проверки подписки приглашённого на канал. Повторная выдача за один Telegram ID блокируется. Ссылка использует формат https://t.me/BOT_USERNAME?startapp=ref_TELEGRAM_ID. Чтобы это работало, в BotFather настройте Mini App как Main Mini App (или используйте корректную ссылку с именем приложения, если оно настроено как отдельное приложение). Бот должен быть администратором канала, иначе getChatMember может не работать.

ПРОВЕРКА ПЕРЕД ПУБЛИКАЦИЕЙ:
1. Убедитесь, что все Environment Variables заданы и сохранены.
2. Проверьте, что ADMIN_TELEGRAM_ID — именно ваш числовой Telegram ID.
3. Подключите Persistent Disk и проверьте DATA_DIR=/var/data.
4. Добавьте бота администратором канала.
5. В Telegram откройте Mini App, проверьте подписку, приглашение, изменение вероятностей/цен/остатков и сохранение настроек после перезапуска.

Важно: код проверен на синтаксис в локальной среде. Фактическую работу на вашем Render и в Telegram можно подтвердить только после настройки токена, ID, канала и постоянного диска.

ВАЖНО О СОХРАНЕНИИ ДАННЫХ
Все аккаунты и балансы читаются из JSON-базы в DATA_DIR. Для постоянного хранения на Render подключите Persistent Disk, Mount Path: /var/data, переменная DATA_DIR=/var/data. При обычном деплое с тем же диском существующие балансы и остальные данные сохраняются, даже если игрок не заходил неделю или дольше. Если диска нет или его удалить, Render может удалить локальные данные.


ОБНОВЛЕНИЕ: ОБМЕН С ВЫБОРОМ КОЛИЧЕСТВА
- В магазине игрок выбирает количество одинаковых наград от 1 до 100 за одну операцию.
- Сервер проверяет баланс и остаток товара, списывает общую стоимость и выдаёт отдельный код на каждую единицу.
- В админ-панели удалён блок индивидуального управления прокрутками игроков. Общий дневной лимит и бесплатные прокрутки по-прежнему настраиваются в общих настройках.
- Код проверен на синтаксис локально; перед использованием проверьте обмен в Telegram после деплоя.
